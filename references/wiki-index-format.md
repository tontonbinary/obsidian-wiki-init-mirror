# Wiki 索引格式规范

> 定义 obsidian-wiki-init 生成的 index.md 和 _index.md 的标准格式。
> 本规范是 SCHEMA.md 的格式约定，Agent 执行 compile 时必须遵守。

---

## 一、索引类型

| 类型 | 位置 | 作用 |
|------|------|------|
| **根目录 index.md** | `{vault}/index.md` | 全局导航，汇总所有分类 |
| **分类 _index.md** | `{vault}/wiki/{分类}/_index.md` | 单个分类内的页面索引 |

---

## 二、根目录 index.md 格式

```markdown
# Wiki 索引

> {vault-name} 的外部知识库导航页
> Vault 路径：`{vault-path}`

---

## {分类名}

{一句话说明本分类的范围}

- [[Page-名]] — 简短描述（可选）
  - 来源：xxx / 更新：YYYY-MM-DD / 状态：⚠️待验证

---

## {分类名}

...

---

*最后更新：YYYY-MM-DD*
```

### 示例

```markdown
# Wiki 索引

> 小娴的外部知识库导航页

---

## 项目

项目相关的设计、决策、配置

- [[ChatERP]] — AI 进销存助手
  - 来源：MEMORY.md / 更新：2026-04-21
- [[Mauto多级记忆设计]] — Agent 记忆架构设计
  - 来源：设计文档 / 更新：2026-04-20 / 状态：⚠️待验证

---

*最后更新：2026-04-25*
```

---

## 三、分类 _index.md 格式

```markdown
# {分类名} 索引

## 概述
一句话说明本分类的范围

## 页面列表
<!-- 按修改时间倒序，最新在上 -->

- [[Page-名]] — 简短描述
  - 来源：xxx / 更新：YYYY-MM-DD / 状态：⚠️待验证

---

*最后更新：YYYY-MM-DD*
```

### 示例

```markdown
# 项目 索引

## 概述
有明确阶段性成果的工作集合

## 页面列表

- [[ChatERP]] — AI 进销存助手
  - 来源：MEMORY.md / 更新：2026-04-21
- [[Mauto多级记忆设计]] — Agent 记忆架构
  - 来源：设计文档 / 更新：2026-04-20 / 状态：⚠️待验证

---

*最后更新：2026-04-25*
```

## 四、格式规则

### 4.1 分隔符

- 正文分隔：`— `（U+2014 无前后空格）
- Metadata 分行：使用 `  - `（两个空格 + dash）

**错误示例：**
```markdown
[[Page]] —描述  — 来源：xxx（多余空格、混用）
[[Page]]— > 来源：xxx（分隔符错误）
```

**正确示例：**
```markdown
[[Page]] — 描述
  - 来源：xxx / 更新：2026-04-25
```

### 4.2 Metadata 行

每条页面后可跟一行 metadata，格式统一为：

```
  - 来源：xxx / 更新：YYYY-MM-DD / 状态：⚠️待验证
```

| 字段 | 说明 | 必填 |
|------|------|------|
| 来源 | 原始来源 | 建议填 |
| 更新 | 最后修改日期 | 建议填 |
| 状态 | ⚠️待验证 / ❌已纠正 / 🆕新 | 可选 |

### 4.3 页面排序

- 默认按修改时间倒序（最新在上）
- 同日期的按字母顺序

### 4.4 状态标签

| 标签 | 含义 |
|------|------|
| ⚠️待验证 | 不确定，需要找方法/求证后移除 |
| ❌已纠正 | 已验证为错误并纠正 |
| 🆕新 | 新创建页面（7天内） |

### 4.5 空分类

```markdown
## {分类名}

> 当前暂无文件

---
```

## 五、Agent compile 后的 index 更新规则

1. **新增页面**：在对应分类下插入新页面，按修改时间重新排序
2. **更新页面**：更新该页面的 metadata 行（来源/更新/状态）
3. **删除页面**：从列表中移除，不保留悬空链接
4. **状态变更**：页面从 ⚠️待验证 变为确认后，移除状态标注

## 六、lint 检查清单

- [ ] 分隔符统一使用 `— `（无多余空格）
- [ ] Metadata 字段无混用格式
- [ ] 页面列表按修改时间倒序
- [ ] 已删除页面的链接已移除
- [ ] 空分类使用规定格式
- [ ] 最后更新时间已更新
